# Best prompt for generating HTML websites with DeepSeek

Starter prompt: 
“In a single responsive html file which comprise css and js, don't indent spaces in code, use line breaks instead for readability, don't add comment to code, provide in format i can run in chat. . .”

Followed by logo link (or description if text) + colors + font + responsive behaviour.

**“In a single responsive html file which comprise css and js. . .”** ensures DeepSeek doesn’t separate the codebase into three files, and you can run it in chat. It can be expected that the AI’s initial output will require finetuning, this prompt ensures you can view the HTML page and input an informed prompt.

“. . . don't indent spaces in code, use line breaks instead for readability. . .” 

“. . .provide in format I can run in chat. . .” Sometimes, DeepSeek provides HTML as a minified text you can’t preview in chat, adding this in the prompt reduces the likelihood of that happening. In the event that it outputs as plain text, you can repeat it as a standalone sentence.
“ provide fully updated html” add this to you consecutive corrective prompts to ensure DeepSeek provides the requested edit in the full HTML file and not as a component.
